## 在线修改数据（Cloudflare D1 + Pages Functions + Access）
- 经 grill-me 敲定方案，把「静态 JSON + 本地 node 写回」改成「D1 在线数据库」：
  - 存储：D1 表 `templates`，只存一行（id=1 + `data` TEXT 存整份模板数组 JSON）。
  - 接口：`functions/api/templates.js`（GET 公开读全量）、`functions/api/admin/templates.js`（POST 写全量，upsert `ON CONFLICT(id) DO UPDATE`）。
  - 鉴权：Cloudflare Access 保护 `/admin.html` 与 `/api/admin/*`；删掉前端 SHA-256 弱密码登录。
  - 前台：`script.js` 里 `templates` 改 `let`，首屏兜底渲染后 `fetch /api/templates` 覆盖。
  - 后台：删登录遮罩/导入/导出，`saveAll` 改 POST 写库、`restoreDefaults`（文案「放弃修改」）改重新 GET 拉取。
- 关键坑：**Cloudflare Access 按路径拦、不区分 HTTP method**，所以读写拆路径（读 `/api/templates` 公开、写 `/api/admin/templates` 受保护），否则前台匿名 GET 也会被挡。
- 首次 seed：云端表空时前后台回退到 `script.js` 内置 `defaultTemplates` 兜底，后台点一次「保存到云端」即完成 seed，无需单独建种子数据。

- 待用户手动：D1 建库建表（`CREATE TABLE templates(id INTEGER PRIMARY KEY, data TEXT NOT NULL)`）、Dashboard 绑定 `DB`、配 Access、部署、首次 seed。
