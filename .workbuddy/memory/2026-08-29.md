## 在线修改数据（Cloudflare D1 + Pages Functions + Access）
- 经 grill-me 敲定方案，把「静态 JSON + 本地 node 写回」改成「D1 在线数据库」：
  - 存储：D1 表 `templates`，只存一行（id=1 + `data` TEXT 存整份模板数组 JSON）。
  - 接口：`functions/api/templates.js`（GET 公开读全量）、`functions/api/admin/templates.js`（POST 写全量，upsert `ON CONFLICT(id) DO UPDATE`）。
  - 鉴权：Cloudflare Access 保护 `/admin.html` 与 `/api/admin/*`；删掉前端 SHA-256 弱密码登录。

## 部署失败排查 · 第二轮（关键结论）
- `wrangler deploy` → 报 Missing entry-point（Workers 命令，不对）。
- 改 `npx wrangler pages deploy .` → 报 `Authentication error [code: 10000]`：**Pages 的 Git 构建环境不会注入有权限的 CLOUDFLARE_API_TOKEN**，wrangler 认证失败。这条路要配 token Secret，太折腾，放弃。
- **根因**：仓库里有 `wrangler.toml` → Cloudflare Pages 强制切成「Wrangler 驱动部署」模式 → 部署命令/版本命令变成必填且无法清空。
- **最终方案**：把 `wrangler.toml` 移出仓库（本地保留），退回传统 Pages Git 集成（Cloudflare 自己部署静态文件 + functions/，什么都不用填）。
